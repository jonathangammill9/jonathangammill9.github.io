# jonathangammill9.github.io

Source for [jonathangammill9.github.io](https://jonathangammill9.github.io): my rice site, a portfolio styled as a Linux rice and inspired by file carving for digital forensics. Plain HTML, CSS and JavaScript, with a cherry blossom and smoke theme.

- Everything on the page lives in `index.html`
- `github-banner.svg` is the animated banner, generated by `resources/banner.py` in the [profile repo](https://github.com/jonathangammill9/jonathangammill9)
- `bg.svg` is the smoke and film-grain background
